            NPZ formatting guidelines

            Upload tips

            • Ensure arrays are named meaningfully to ease selection.
            • Keep individual arrays under a few million elements for faster previews.
            • Include a description field in the metadata to document experiment context.

            Data upload requirements

            Review the guidelines before adding files to a project.

            Supported file formats

            • .npy (single NumPy array)
            • .npz (multiple NumPy arrays inside one compressed file)
            • Only NumPy arrays are supported

            Data types

            • Arrays must contain numeric values only

            Time series alignment

            • Time alignment is based on row index, not timestamps
            • Arrays that are meant to be synchronized must have the same sampling rate
            • Different array lengths are allowed. Alignment stops when the shortest array ends

            Multi-subject data

            • Multi-subject uploads are supported
            • The first column must contain the subject ID
            • Subject IDs must be numeric (integer or float), not strings
            • Chronological order must be preserved within each subject
